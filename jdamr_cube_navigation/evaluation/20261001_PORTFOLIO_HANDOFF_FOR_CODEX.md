# Codex 인계: JD-AMR 서빙 주행 포트폴리오 사례 작성 자료 (2026-10-01)

이 문서는 포트폴리오 사례 페이지를 쓰기 위한 입력 자료다. 수치는 모두 저장소 로그와 bag에서 뽑은 값이고, 출처 파일을 함께 적었다. 사례 문안은 이 문서의 사실 범위 안에서만 쓴다.

## 1. 프로젝트 요약

- 이름(가제): 지도 기반 서빙 주행과 RGB-D 박스 면 정렬·5 cm 정밀 주차·후면 도킹
- 시나리오: 충전 도크 출발 → 물 받는 곳 박스 앞 5 cm 정지·5초 대기 → 후진 이탈 → 호출 테이블 박스 앞 5 cm 정지·5초 대기 → 후진 이탈 → 도크 대기점 → 후면 도킹. 5초 대기는 최종 시스템(양팔 로봇)에서 팔 작업 완료 신호가 들어갈 자리다.
- 하드웨어: 직사각형 차동구동 차체(바퀴 포함 폭 0.540 m, 길이 0.340 m), Raspberry Pi 4, YDLIDAR G4, Orbbec Astra RGB-D, ESP32 모터 보드.
- 소프트웨어: ROS 2 Jazzy, Nav2 1.3.12, Cartographer 2D 지도, AMCL, NavFn 전역 경로, Regulated Pure Pursuit(RPP) 추종, Collision Monitor, 자체 박스 실행기(`box_service`).
- 차체 특징: 회전 중심(base_footprint)에서 앞 0.085 m, 뒤 0.295 m로 뒤가 길다(모서리 회전 반경 0.414 m). 이 비대칭이 여러 설계 결정의 출발점이다.

- 수치는 "로봇 내부 추정(AMCL·odom 기준)"으로 표기한다. 외부 줄자 실측값처럼 쓰지 않는다.
