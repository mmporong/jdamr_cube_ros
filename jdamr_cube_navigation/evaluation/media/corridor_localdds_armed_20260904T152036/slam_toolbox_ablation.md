# 동일 MCAP 2D SLAM 백엔드 비교

## 실험 조건

- 동일한 실물 복도 주행 MCAP을 격리된 ROS domain에서 재생했다.
- 저장 지도와 이동 명령은 재생하지 않았고, 기록된 AMCL `map→odom`은 제거했다.
- 각 실행에서는 mapping backend 하나만 `map→odom` 권한을 가졌다.
- 외부 ground truth가 없으므로 아래 값은 ATE/RPE가 아니다.

## 결과

| 백엔드/조건 | 추정 경로 | 시작–종료 | AMCL 기준 정렬 RMS | AMCL 기준 최대 편차 | 지도 범위 |
|---|---:|---:|---:|---:|---:|
| cartographer | 84.536m | 1.026m | 0.553m | 1.411m | 46.35×12.15m |
| slam_toolbox | 85.410m | 3.002m | 1.152m | 2.611m | 47.35×20.2m |
| slam_toolbox_range35 | 84.426m | 2.764m | 0.963m | 2.380m | 44.25×9.65m |
| slam_toolbox_range35_dense | 87.034m | 1.032m | 0.817m | 2.058m | 44.75×10.3m |
| slam_toolbox_range35_dense_noloop | 84.827m | 2.774m | 1.008m | 2.359m | 45.35×10.1m |

## 선택

`cartographer`를 현재 복도 데이터의 기본 백엔드로 선택한다. 시작–종료 불일치는 1.026m와 1.032m로 수치상 유사했고, 저장 지도 AMCL 기준 정렬 RMS는 1.48배 작았다.

이 비교는 백엔드의 절대 정확도를 증명하지 않는다. 같은 센서 입력에서 폐루프 구조와 저장 지도 기준 일관성을 얼마나 유지했는지를 비교한 결과다.
